# Como publicar este perfil en GitHub

Este repositorio debe tener exactamente el mismo nombre que tu usuario de GitHub.

Si tu usuario es `santy8151`, el repositorio debe llamarse:

```text
santy8151
```

## Pasos

1. Crea un repositorio publico en GitHub con el mismo nombre de tu usuario.
2. Sube estos archivos:
   - `README.md`
   - `assets/banner.svg`
   - `.gitignore`
3. Entra a `https://github.com/TU_USUARIO` y GitHub mostrara este README como perfil.

## Comandos sugeridos

```powershell
git init
git add README.md assets/banner.svg .gitignore
git commit -m "Create GitHub profile README"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_USUARIO.git
git push -u origin main
```
